# 0002 — Deterministic Authored Tactics

**Status:** Accepted

## Context

Automated implementation can execute explicit rules and tests reliably, but cannot rescue an opaque
balance space by intuition. Random accuracy, procedural maps, and broad systemic interactions multiply
the number of situations requiring subjective tuning.

## Decision

Use authored maps and encounters, exact damage, visible enemy intents, and scheduled previewed habitat
shifts. Keep the familiar two-action tactical grammar. Express variety through objectives, terrain,
unit roles, and bounded character skills.

## Consequences

Players can reason from displayed information, and agents can test concrete invariants. Replay
variation is lower than in a procedural game. Content authors must create strong encounter layouts,
but each can be evaluated and tuned as a known state space.
